Atur target tabungan

Cara menggunakan app

1. Atur target. Tekan Pengaturan lalu isi saldo awal yang benar-benar dimiliki, tujuan, dan rencana setoran bulanan.

2. Catat setoran dan penarikan. Aplikasi tidak memindahkan uang ke rekening. Transfer uang secara terpisah melalui aplikasi bank, lalu catat nominalnya di sini.

3. Pasang di Android. Upload seluruh folder aplikasi ke GitHub Pages atau hosting HTTPS. Buka tautannya di Chrome Android → menu ⋮ → Tambahkan ke layar utama / Instal aplikasi. File HTML yang dibuka langsung belum mendukung instalasi PWA.

4. Backup. Tekan Unduh cadangan sebelum berganti perangkat atau menghapus data browser. Fitur Pulihkan cadangan dapat mengembalikan data yang pernah diekspor.

Penting: catatan ini hanya disimpan di browser pada perangkat yang dipakai. Menghapus data situs atau mengganti browser dapat menghapusnya. Aplikasi tidak tersambung ke Bank Jago maupun bank lain.
